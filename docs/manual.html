Cheat-sheet — common tasks

Backspace — hold left-outer thumb (EXT), tap J position
Maximize window — EXT + S+D + ↑
Screenshot (snip) — J+K
Send window to thinkvision — EXT + S+D + ↓
Mouse on/off — tap X+C
Switch BT profile — both left thumbs → BT0..BT5
FancyZones cycle — D+F
Recover stuck modifier — both left thumbs → unstick
Function keys — both outer thumbs → F-row
PrintScreen (full) — both outer thumbs + K position
Sticky mods (sLA/sLG/sLS/sLC) on EXT/FNC: tap once, applies to next key. Print A4 · CTRL+P
